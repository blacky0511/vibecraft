# 프로젝트 시작

vibecraft:project-kickoff 스킬을 호출하여 새 프로젝트를 시작한다.

## 동작

1. 아이디어 정리 (brainstorming)
2. 기술 스택 선택
3. 프로젝트 초기 설정 (scaffold)
4. 구현 계획 수립 (writing-plans)
5. RPDCA 워크플로우로 합류

## 다음 단계

초기 설정 완료 후 → `/plan` 또는 `/execute`로 이어간다.

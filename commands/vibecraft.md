# vibecraft 도움말

다음 내용을 사용자에게 보여주세요:

## vibecraft - 바이브코딩 네비게이션

### 자동 감지 모드
작업을 요청하면 자동으로 감지됩니다:
- **새 기능**: "~만들어줘", "~추가해줘", "~구현해줘"
- **디버깅**: "~에러", "~안 돼", "~버그", "~오류"
- **단순 수정**: "~키워줘", "~색상 바꿔", "~폰트"
- **프로젝트 시작**: "~만들자", "~앱", "~사이트"
- **코드 리뷰**: "~리뷰해줘", "~봐줘", "~검토"
- **배포**: "~배포", "~릴리즈"

### 단축 명령어
- `/pdca` — PDCA 상태 확인 / 단계 이동
- `/review` — 코드 리뷰 시작
- `/debug` — 체계적 4단계 디버깅

### 작업 크기별 워크플로우 (스마트 PDCA)
- **S (소)**: 파일 1~2개 → 바로 실행 → 검증
- **M (중)**: 파일 3~5개 → 계획 → 실행 → 검증
- **L (대)**: 파일 6개+ → brainstorming → 계획 → 설계 → 팀 구성 → 병렬 실행 → 리뷰 → 검증

### 철칙 (Iron Law)
1. 테스트 먼저 작성 (TDD)
2. 증거 없이 완료 없다

### 안전 가드 (자동 적용)
- 파일 수정 전: 영향 범위 분석 (PreToolUse 훅)
- 커밋 전: 테스트 실행 여부 확인 (commit-guard)
- 위험한 Git 명령어 감지 시 경고 (git-safety-guard)

### 다단계 리뷰 파이프라인
1. code-simplifier: 코드 정리 + 품질
2. external-reviewer: 외부 도구 검증 (선택)
3. gap-detector: 설계 대비 달성률

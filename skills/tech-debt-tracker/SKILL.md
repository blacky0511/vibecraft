# 기술 부채 트래커 (Tech Debt Tracker)

## 역할

"일단 이렇게 하고 나중에 고치자"를 기록하고, 잊지 않게 리마인드한다.

## 부채 파일

- **위치**: `docs/tech-debt.md`
- **형식**: 마크다운 테이블

```markdown
# 기술 부채 목록

| # | 내용 | 파일 | 발생일 | 심각도 | 상태 |
|---|------|------|--------|--------|------|
| 1 | API 에러 처리 통일 필요 | src/api/*.ts | 2026-02-27 | 중 | 대기 |
| 2 | 로그인 토큰 갱신 미구현 | src/auth/token.ts | 2026-02-27 | 상 | 대기 |
```

## 자동 기록 조건

다음 상황에서 부채를 자동 기록한다:

- AI 또는 사용자가 "일단", "나중에", "임시로" 라고 말한 경우
- 하드코딩된 값을 넣은 경우 (설정으로 분리해야 하지만 일단 넣은 것)
- TODO 주석을 코드에 남긴 경우
- 에러 처리를 생략한 경우
- 테스트를 생략한 경우 (iron-law 예외 상황)

## 리마인드 타이밍

- **작업 시작 시**: "밀린 기술 부채 3건이 있습니다" (심각도 높은 것 먼저)
- **관련 파일 수정 시**: "이 파일에 기술 부채 1건이 있습니다: ~"
- **여유 시간 감지 시**: "시간 되면 기술 부채 정리하시겠어요?"

## 심각도 기준

| 심각도 | 기준 | 예시 |
|--------|------|------|
| 상 | 보안 위험 또는 데이터 손실 가능 | 비밀번호 평문 저장 |
| 중 | 유지보수 어려움 또는 성능 저하 | 중복 코드, N+1 쿼리 |
| 하 | 코드 품질/가독성 문제 | 네이밍 불일치, 주석 부족 |

## 부채 해소 시

부채 항목이 해결되면 상태를 "완료"로 변경하고 해결일을 기록한다.
완료된 항목이 10개 이상 쌓이면 완료 항목을 아카이브한다.

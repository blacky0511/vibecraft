# Claude Code 사용법 학습 가이드

이 문서는 사용자가 "클로드코드 사용법 알려줘"라고 했을 때 읽어서 안내하는 콘텐츠입니다.
한번에 전부 보여주지 말고, 단계별로 나눠서 안내하세요.

---

## 1단계: Claude Code가 뭔가요? (5분)

### 한 줄 요약

Claude Code는 **터미널에서 AI와 대화하면서 코딩하는 도구**입니다.

### 일반 ChatGPT/Claude와 뭐가 다른가요?

| 일반 AI 채팅 | Claude Code |
|-------------|-------------|
| 코드를 복사해서 붙여넣기 | AI가 직접 파일을 읽고 수정 |
| "이 코드 고쳐줘" → 코드 블록 제공 | "고쳐줘" → 파일을 직접 수정해줌 |
| 프로젝트 구조를 모름 | 프로젝트 전체를 이해하고 작업 |
| 한 번에 하나만 | 여러 에이전트가 동시에 작업 가능 |

### 지금 여기가 Claude Code입니다

지금 대화하고 있는 이 화면이 Claude Code입니다.
여기서 말하면 AI가 직접 파일을 만들고, 코드를 수정하고, 테스트를 실행합니다.

**실습:** `"이 프로젝트 파일 구조 보여줘"`라고 입력해보세요.

## 2단계: 기본 사용법 (10분)

### 대화하듯 시키면 됩니다

```
"src/app/page.tsx 파일 읽어줘"         → 파일 내용을 보여줌
"이 함수에서 에러 처리 추가해줘"        → 코드를 직접 수정함
"npm test 실행해줘"                   → 터미널 명령어를 실행함
"login이라는 단어가 어디서 쓰이는지 찾아줘" → 프로젝트 전체에서 검색
```

### AI가 사용하는 도구들

AI는 내부적으로 여러 도구를 사용합니다. 알 필요는 없지만 이해하면 도움이 됩니다:

| 도구 | 하는 일 | 예시 |
|------|---------|------|
| **Read** | 파일 읽기 | 코드 내용 확인 |
| **Write** | 파일 생성 | 새 파일 만들기 |
| **Edit** | 파일 수정 | 코드 일부만 변경 |
| **Bash** | 명령어 실행 | npm install, git commit |
| **Glob** | 파일 찾기 | "*.tsx" 파일 전부 찾기 |
| **Grep** | 내용 검색 | "fetchUser"가 쓰인 곳 검색 |
| **Agent** | 서브에이전트 | 복잡한 작업을 나눠서 병렬 처리 |

### 허가 모드

AI가 파일을 수정하거나 명령어를 실행할 때 **허가를 물어볼 수 있습니다.**

- **y**: 허가 (이번만)
- **a**: 항상 허가 (이 세션 동안)
- **n**: 거부

**실습:** `"package.json 파일 읽어줘"`라고 입력하고 AI가 Read 도구를 사용하는 걸 관찰해보세요.

## 3단계: 효율적으로 쓰는 팁 (15분)

### 팁 1: 구체적으로 말하세요

```
❌ "코드 고쳐줘"
✅ "src/auth/login.ts에서 비밀번호 검증 로직이 빈 문자열을 허용하는 버그 고쳐줘"
```

### 팁 2: 에러 메시지를 통째로 붙여넣으세요

```
이 에러 고쳐줘:

TypeError: Cannot read properties of undefined (reading 'map')
    at UserList (src/components/UserList.tsx:15:23)
    at renderWithHooks (react-dom.development.js:16305:18)
```

AI가 에러 메시지를 분석해서 정확한 원인을 찾아줍니다.

### 팁 3: `!` 로 직접 명령어 실행

프롬프트에 `!`를 앞에 붙이면 터미널 명령어를 직접 실행할 수 있습니다.

```
! npm run dev          ← 개발 서버 실행
! git status           ← Git 상태 확인
! ls src/              ← 폴더 내용 확인
```

### 팁 4: 컨텍스트를 알려주세요

```
"이 프로젝트는 Next.js 14 + Tailwind + Prisma를 사용해.
회원가입 페이지를 만들어줘. 이메일/비밀번호 방식이고,
가입 후 /dashboard로 리다이렉트해줘."
```

배경 정보를 충분히 주면 AI가 더 정확한 코드를 작성합니다.

### 팁 5: 되돌리기

AI가 잘못 수정했으면:
```
"방금 수정한 거 되돌려줘"    → AI가 git으로 복구
! git diff                 → 변경된 내용 확인
! git checkout -- 파일경로   → 특정 파일 원래대로
```

**실습:** `! git log --oneline -5`를 입력해서 최근 커밋 5개를 확인해보세요.

## 4단계: 고급 기능 (20분)

### CLAUDE.md — AI에게 규칙 알려주기

프로젝트 루트에 `CLAUDE.md` 파일을 만들면, AI가 항상 그 규칙을 따릅니다.

```markdown
# 프로젝트 규칙

## 코딩 스타일
- TypeScript 사용 필수
- 함수형 컴포넌트만 사용
- Tailwind CSS로 스타일링

## 네이밍
- 컴포넌트: PascalCase
- 함수/변수: camelCase
- 파일: kebab-case
```

### 서브에이전트 — 여러 AI가 동시에

큰 작업을 여러 AI에게 나눠서 동시에 처리할 수 있습니다.

```
"프론트엔드와 백엔드를 동시에 작업해줘"
→ AI가 자동으로 에이전트 2개를 만들어 병렬 처리
```

### MCP 서버 — 외부 도구 연결

Claude Code에 외부 도구를 연결할 수 있습니다.
예: Playwright (브라우저 자동화), GitHub, Slack 등

```
"Playwright로 이 사이트 스크린샷 찍어줘"
→ MCP 서버를 통해 실제 브라우저를 제어
```

### 플러그인 — 기능 확장

vibecraft처럼 플러그인을 설치해서 Claude Code를 확장할 수 있습니다.

```
/plugin                    ← 플러그인 관리 메뉴
/plugin marketplace        ← 마켓플레이스에서 설치
```

### 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl+C` | 현재 작업 중단 |
| `Ctrl+L` | 화면 클리어 |
| `↑` / `↓` | 이전/다음 입력 |
| `Esc` | 입력 취소 |
| `/clear` | 대화 초기화 |
| `/compact` | 컨텍스트 압축 |

**실습:** `/compact`를 입력해서 컨텍스트 압축이 어떻게 작동하는지 확인해보세요. (대화가 길어졌을 때 유용합니다)

## 5단계: 문제 해결 (참고)

### AI가 엉뚱한 파일을 수정할 때
```
"잠깐, 그 파일 말고 src/auth/login.ts만 수정해줘"
```

### AI가 너무 많은 걸 한꺼번에 할 때
```
"하나씩 하자. 먼저 로그인 기능만 만들어줘"
```

### AI가 오래된 정보를 쓸 때
```
"Next.js 최신 버전 문서를 참고해줘" → context7 MCP가 최신 문서를 가져옴
```

### 대화가 너무 길어졌을 때
```
/compact    ← 이전 대화를 압축해서 컨텍스트 확보
/clear      ← 완전히 새로 시작
```

## 안내 방법

- 사용자에게 1~5단계를 **한번에 다 보여주지 않는다**
- "다음", "계속", "더 알려줘"라고 하면 다음 단계로 진행
- 각 단계 끝에 **실습 과제**를 포함한다
- 실습 결과를 보면서 부가 설명을 해준다
- 사용자 수준에 맞게 깊이를 조절한다 (초보면 1~3단계 집중, 중급이면 4~5단계)

# 환영 가이드 (Welcome Guide)

## 역할

사용자가 인사하거나 처음 접할 때, vibecraft 사용법과 개발 학습 가이드를 안내한다.

## 활성화 조건

- 인사: "안녕", "하이", "hi", "hello"
- 탐색: "뭐 할 수 있어?", "도움", "help", "시작"
- 첫 사용 감지: 세션 시작 후 첫 메시지가 짧은 인사일 때

## 응답 형식

아래 형식으로 환영 메시지를 출력한다.

```markdown
# 👋 안녕하세요! vibecraft에 오신 걸 환영합니다.

vibecraft는 **바이브코딩을 하면서 자연스럽게 개발자로 성장**하도록 돕는 AI CTO입니다.
아이디어만 말해주세요. 나머지는 제가 알아서 진행합니다.

---

## 🎯 이렇게 말해보세요

### 뭔가 만들고 싶을 때
- `"로그인 기능 만들어줘"` → 설계부터 구현까지 단계별 안내
- `"블로그 사이트 만들자"` → 프로젝트 시작 가이드

### 문제를 고치고 싶을 때
- `"로그인이 안 돼"` → 체계적 4단계 디버깅
- `"이 에러 봐줘"` + 에러 메시지 붙여넣기

### 코드를 점검하고 싶을 때
- `"코드 리뷰해줘"` → 품질/보안/성능 체크
- `"배포해줘"` → 배포 전 체크리스트

### 간단한 수정
- `"폰트 크기 키워줘"` → 파일 위치 알려주고 직접 할지 물어봄

---

## 🧠 vibecraft가 자동으로 해주는 것

| 기능 | 설명 |
|------|------|
| 🔍 **상황 자동 감지** | 말투만으로 새 기능/버그/리뷰 모드 자동 선택 |
| 📏 **작업 크기 판단** | S/M/L로 자동 분류, 크기에 맞는 워크플로우 |
| 🛡️ **품질 관리** | 영향 범위 분석, 중복 체크, 일관성 감시 |
| 💡 **CTO 의견** | 잘못된 방향이면 근거와 대안을 제시 |
| 📚 **개발 지식** | 코드 작성하면서 자연스럽게 개발 용어/패턴 학습 |

---

## ⚡ 빠른 시작

지금 바로 아래 중 하나를 입력해보세요:

1. `"새 프로젝트 만들자"` → 처음부터 시작
2. `"이 프로젝트 분석해줘"` → 기존 코드 파악
3. `"뭐 개선할 수 있어?"` → 현재 코드 점검

---

## 📖 더 알고 싶다면

- `"/vibecraft"` → 전체 명령어 + 스킬 목록
- `"/output-style"` → 응답 스타일 변경 (학습모드/간결모드)
```

## 학습 가이드 (learning output style일 때 추가)

learning 모드가 활성화되어 있으면 아래 섹션도 추가한다:

```markdown
---

## 📚 개발자 성장 로드맵

vibecraft를 쓰면서 자연스럽게 배우게 되는 것들:

**🟢 입문 (지금 바로)**
- 변수, 함수, 조건문 → 코드를 읽을 수 있게 됨
- Git 기초 → "커밋해줘"를 이해하게 됨
- 파일 구조 → 어디에 뭐가 있는지 파악

**🟡 중급 (1~2주 후)**
- 컴포넌트 설계 → 재사용 가능한 코드를 이해
- API 호출 → 서버와 통신하는 방법
- 테스트 작성 → 내 코드가 맞는지 검증

**🔴 고급 (1~2개월 후)**
- 아키텍처 패턴 → 큰 그림을 설계
- 성능 최적화 → 빠른 앱 만들기
- 배포 파이프라인 → 앱을 세상에 공개

매 작업마다 💡 **Learning Point**에서 하나씩 알려드립니다!
```

## 트리거 연동

UserPromptSubmit 훅에서 인사/탐색 패턴을 감지하면 이 스킬을 호출한다.
다른 모드(새 기능, 디버깅 등)로 명확히 판별되면 이 스킬은 스킵한다.

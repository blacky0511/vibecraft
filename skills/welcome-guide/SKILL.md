# 환영 가이드 (Welcome Guide)

## 역할

사용자가 인사하거나 처음 접할 때, 3가지 선택지를 제안한다.

## 활성화 조건

- 인사: "안녕", "하이", "hi", "hello", "뭐해", "야"
- 탐색: "뭐 할 수 있어?", "도움", "help", "시작"
- 첫 사용: 세션 시작 후 첫 메시지가 짧은 인사일 때

## 응답 형식

아래 형식으로 **반드시** 3가지 선택지를 제시한다.

```markdown
# 안녕하세요! 무엇을 도와드릴까요?

vibecraft는 아이디어만 말하면 AI가 설계부터 구현까지 진행하는 바이브코딩 도구입니다.

---

## 1. 바로 작업 시작하기

어떤 작업을 하고 싶으세요?

- **새 프로젝트** → `"쇼핑몰 만들자"`, `/kickoff 프로젝트이름`
- **기능 추가/수정** → `"로그인 기능 만들어줘"`, `/feature 설명`
- **에러/버그 수정** → `"로그인이 안 돼"`, `/debug 증상`
- **코드 리뷰** → `"코드 봐줘"`, `/review`
- **배포** → `"서버에 올려줘"`, `/deploy`
- **패킷/API 추출** → `"이 사이트 API 따줘"`, `/packet URL`
- **네이버 자동화** → `"네이버 블로그 진단해줘"`, `/naver 증상`

그냥 하고 싶은 걸 편하게 말씀하세요. AI가 자동으로 알아듣습니다.

---

## 2. vibecraft 사용법 배우기

vibecraft 플러그인을 제대로 활용하는 방법을 단계별로 배울 수 있습니다.

→ `"vibecraft 사용법 알려줘"` 라고 입력하세요

배우는 내용:
- 명령어 사용법 (15개 전체)
- 자동 감지가 되는 말투 예시
- RPDCA 워크플로우 이해하기
- 에이전트 팀 활용하기

---

## 3. Claude Code 사용법 배우기

Claude Code(이 터미널 도구)를 더 잘 쓰는 방법을 배울 수 있습니다.

→ `"클로드코드 사용법 알려줘"` 라고 입력하세요

배우는 내용:
- 기본 사용법과 단축키
- 파일 읽기/수정/검색 도구
- 서브에이전트와 병렬 작업
- 플러그인과 MCP 서버 활용
- 효율적인 프롬프트 작성법
```

## 선택지별 후속 처리

### 사용자가 1번 (작업 시작)을 선택하면
→ 사용자의 요청에 맞는 스킬이 자동으로 호출된다 (훅이 감지)

### 사용자가 2번 (vibecraft 공부)을 선택하면
→ `references/learn-vibecraft.md`를 읽고 단계별로 안내한다.
→ 사용자가 "vibecraft 사용법", "vibecraft 배우기", "vibecraft 공부" 등을 입력하면 이 경로로 진입

### 사용자가 3번 (Claude Code 공부)을 선택하면
→ `references/learn-claude-code.md`를 읽고 단계별로 안내한다.
→ 사용자가 "클로드코드 사용법", "claude code 배우기" 등을 입력하면 이 경로로 진입

## 학습 모드 감지 패턴

아래 표현이 들어오면 해당 학습 가이드를 읽어서 안내한다:

| 입력 | 행동 |
|------|------|
| "vibecraft 사용법", "vibecraft 배우기", "명령어 알려줘" | references/learn-vibecraft.md 읽고 안내 |
| "클로드코드 사용법", "claude code 배우기", "클코 사용법" | references/learn-claude-code.md 읽고 안내 |
| "사용법", "배우고 싶어", "공부하고 싶어" | 2번과 3번 선택지를 다시 제시 |

## 트리거 연동

UserPromptSubmit 훅에서 인사/탐색 패턴을 감지하면 이 스킬을 호출한다.
다른 모드(새 기능, 디버깅 등)로 명확히 판별되면 이 스킬은 스킵한다.

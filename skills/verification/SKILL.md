# 완료 전 검증

## 역할
모든 작업이 끝나기 전에 아래 체크리스트를 강제 실행한다.

## 검증 체크리스트

### 1. 테스트 확인
- [ ] 관련 테스트가 모두 통과하는가?
- [ ] 새로 추가한 코드에 대한 테스트가 있는가?
- [ ] 테스트 실행 결과를 캡처했는가?

### 2. 동작 확인
- [ ] 변경 사항이 의도대로 동작하는가?
- [ ] 기존 기능이 깨지지 않았는가?
- [ ] 에러/경고가 없는가?

### 3. 코드 품질
- [ ] 불필요한 console.log/print가 남아있지 않은가?
- [ ] 하드코딩된 값이 없는가?
- [ ] 보안 취약점(API 키 노출, SQL 인젝션 등)이 없는가?

### 4. 설계 대비 달성률 (M, L 작업만)
- [ ] 계획한 기능이 모두 구현되었는가?
- [ ] 달성률이 90% 이상인가?
- [ ] 미구현 항목이 있다면 이유가 문서화되었는가?

## 검증 결과 보고 형식

```
## 검증 결과

### 테스트
- 실행: `npm test` (또는 해당 명령어)
- 결과: 15/15 통과 ✓

### 동작 확인
- [변경 전]: 로그인 버튼 클릭 시 에러
- [변경 후]: 정상 로그인 + 대시보드 이동

### 달성률
- 계획 항목: 5개
- 완료 항목: 5개
- 달성률: 100%

### 결론: 완료 ✓
```

## 검증 실패 시

달성률 90% 미만이거나 테스트 실패가 있으면:
1. "검증 실패: [이유]" 알림
2. 미달 항목 목록 제시
3. 수정 후 재검증
4. 재검증 통과 시 완료 선언

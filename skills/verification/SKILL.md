# 완료 전 검증

## 핵심 요약

1. **테스트 통과**: 관련 테스트 모두 통과 + 실행 결과 캡처
2. **동작 확인**: 변경 전후 비교, 기존 기능 깨짐 없음
3. **코드 품질**: console.log 잔류 없음, 하드코딩 없음
4. **보안 확인**: 비밀값 하드코딩 없음, 입력 검증, SQL 인젝션/XSS 없음, 에러 정보 노출 없음
5. **달성률** (M·L만): 설계 대비 90% 이상 구현
6. **실패 시**: 미달 항목 제시 → 수정 → 재검증 → 통과 후 완료 선언

---

## 역할
모든 작업이 끝나기 전에 아래 체크리스트를 강제 실행한다.

## 검증 체크리스트

### 1. 테스트 확인
- [ ] 관련 테스트가 모두 통과하는가?
- [ ] 새로 추가한 코드에 대한 테스트가 있는가?
- [ ] 테스트 실행 결과를 캡처했는가?

### 2. 동작 확인
- [ ] 변경 사항이 의도대로 동작하는가?
- [ ] 기존 기능이 깨지지 않았는가?
- [ ] 에러/경고가 없는가?

### 3. 코드 품질
- [ ] 불필요한 console.log/print가 남아있지 않은가?
- [ ] 하드코딩된 값이 없는가?

### 4. 보안 확인
- security-baseline 스킬이 코드 작성 시 자동 적용됨. 별도 체크 불필요.

### 5. 설계 대비 달성률 (M, L 작업만)
- [ ] 계획한 기능이 모두 구현되었는가?
- [ ] 달성률이 90% 이상인가?
- [ ] 미구현 항목이 있다면 이유가 문서화되었는가?

## 검증 결과 보고 형식

```
## 검증 결과

### 테스트
- 실행: `npm test` (또는 해당 명령어)
- 결과: 15/15 통과 ✓

### 동작 확인
- [변경 전]: 로그인 버튼 클릭 시 에러
- [변경 후]: 정상 로그인 + 대시보드 이동

### 달성률
- 계획 항목: 5개
- 완료 항목: 5개
- 달성률: 100%

### 결론: 완료 ✓
```

## 검증 실패 시

달성률 90% 미만이거나 테스트 실패가 있으면:
1. "검증 실패: [이유]" 알림
2. 미달 항목 목록 제시
3. 수정 후 재검증
4. 재검증 통과 시 완료 선언

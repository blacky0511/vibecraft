# 학습 진도 추적 (Skill Progression)

## 역할

사용자가 배운 개발 지식을 추적하여, 아는 건 생략하고 모르는 건 깊이 설명한다.

## 진도 파일

- **위치**: memory 디렉토리의 `user-skills.md`
- **자동 관리**: AI가 학습 이벤트를 감지할 때마다 업데이트

```markdown
# 사용자 개발 실력 추적

## 확인된 개념 (설명 생략 가능)

### 입문
- 변수, 상수 (let, const)
- 함수 선언과 호출
- 조건문 (if/else)
- 배열과 반복문 (for, map)

### 중급
- async/await (비동기 처리)
- API 호출 (fetch)
- 컴포넌트 개념 (React)

## 아직 미확인 개념 (설명 필요)

### 중급
- 상태 관리 (useState, Context)
- 에러 바운더리
- 타입스크립트 제네릭

### 고급
- 디자인 패턴
- 성능 최적화
- CI/CD 파이프라인
```

## 학습 감지 규칙

### 개념을 "알고 있다"로 판단하는 경우
- AI가 설명했고, 사용자가 이해를 표현한 경우 ("아 그렇구나", "이해했어")
- 사용자가 해당 용어를 올바르게 사용한 경우
- 사용자가 직접 해당 패턴의 코드를 작성한 경우

### 설명 레벨 조절
- **첫 등장**: 풀네임 + 비유 + 실제 의미 + 예시 코드
- **두 번째**: "(앞서 배운 ~)" 리마인드 + 새로운 측면 설명
- **세 번째 이후**: 설명 없이 사용. 단, 새로운 맥락이면 추가 설명

## 진도 업데이트 타이밍

- 새 개념을 설명한 후
- 사용자가 이해를 표현한 후
- 사용자가 새 용어를 올바르게 사용한 후

## 주의사항

- 진도 파일이 과도하게 커지지 않게 관리한다 (50줄 이내)
- 확실히 이해한 것만 "확인됨"으로 기록한다
- 사용자가 "이거 다시 설명해줘"라고 하면 즉시 상세 설명 + 진도 재확인

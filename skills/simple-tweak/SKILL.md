# 단순 수정 안내 (Simple Tweak)

## 역할

단순한 수치/스타일 변경 요청을 받으면, 바로 수정하지 않고
**파일 위치와 변경 방법을 먼저 안내**하여 사용자의 학습을 돕는다.

## 감지 조건

다음 조건을 **모두** 만족하면 단순 수정으로 판단한다:

### 1. 변경 대상이 단순 수치/스타일
- 폰트 크기, 굵기
- 간격 (padding, margin, gap)
- 색상 변경
- 너비, 높이, 최대/최소 크기
- 투명도, 둥글기(border-radius)
- 그림자, 보더 두께
- 텍스트 정렬, 줄 높이
- 숫자 값 변경 (제한 수, 타임아웃 등)

### 2. 수정 범위가 좁음
- 1~3줄 이내의 변경
- 한 파일 내 수정
- 로직 변경 없이 값만 교체

### 3. 감지 키워드
- 크기 관련: "키워줘", "줄여줘", "크게", "작게", "늘려줘"
- 간격 관련: "간격", "여백", "띄워줘", "붙여줘", "패딩", "마진"
- 색상 관련: "색", "컬러", "밝게", "어둡게", "진하게", "연하게"
- 폰트 관련: "폰트", "글씨", "굵게", "얇게", "볼드"
- 수치 관련: "~로 바꿔", "~에서 ~로", "숫자", "값"

## 응답 흐름

### Step 1: 위치 파악

먼저 Grep/Glob으로 해당 코드의 **정확한 위치**를 찾는다.
추측하지 않는다. 반드시 실제 파일을 읽어서 확인한다.

### Step 2: 안내 메시지 작성

아래 형식으로 사용자에게 안내한다:

```
📍 수정 위치: `{파일경로}:{줄번호}`

현재 코드:
```{언어}
{현재 코드}
```

변경 방법:
`{현재 값}` → `{변경 값}`

직접 수정하시겠어요, 아니면 제가 바꿔드릴까요?
```

### Step 3: AskUserQuestion으로 선택지 제공

```
질문: "직접 수정하시겠어요?"
선택지:
  1. "직접 할게요" - 위치만 알려주고 끝. 사용자가 에디터에서 직접 수정.
  2. "해줘" - AI가 Edit 도구로 바로 수정.
```

### Step 4: 선택에 따른 행동

**"직접 할게요" 선택 시:**
- 추가 설명이 필요하면 해당 값의 의미를 간단히 설명
- "수정 완료하시면 말씀해주세요!" 로 마무리

**"해줘" 선택 시:**
- Edit 도구로 즉시 수정
- 변경 전/후를 보여주고 완료

## 판단이 애매한 경우

다음의 경우에는 이 스킬을 적용하지 않고 일반 워크플로우로 진행한다:

- 여러 파일에 걸친 수정
- 로직 변경이 포함된 경우
- 새로운 스타일/컴포넌트 추가가 필요한 경우
- 사용자가 구체적 값을 모르고 "적당히"라고 한 경우 (AI 판단 필요)

## 학습 모드 연동

Output Style이 `learning`일 때, 추가로 설명한다:
- 해당 CSS 속성이나 설정 값의 의미
- 관련 단위 설명 (px, rem, em 등의 차이)
- "이런 값은 보통 이 범위에서 조절합니다" 같은 팁

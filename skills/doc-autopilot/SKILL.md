# 문서 자동 관리 (Doc Autopilot)

## 역할

코드를 수정할 때 관련 문서가 오래됐으면 자동으로 감지하고 업데이트를 제안한다.

## 감시 대상

| 문서 | 코드 변경과의 관계 |
|------|-----------------|
| README.md | 설치 방법, API 목록, 환경 변수, 프로젝트 구조 |
| CLAUDE.md | 프로젝트 규칙, 디렉토리 구조, 코딩 규칙 |
| API 문서 | 엔드포인트 추가/삭제/변경 |
| 주석 | 함수 시그니처 변경, 로직 변경 |
| .env.example | 환경 변수 추가/삭제 |

## 감지 타이밍

### 자동 감지

- **API 엔드포인트 추가/변경**: README의 API 목록 업데이트 필요?
- **환경 변수 추가**: .env.example에 추가 필요?
- **디렉토리 구조 변경**: CLAUDE.md의 구조 섹션 업데이트 필요?
- **패키지 추가/삭제**: README의 설치 방법 업데이트 필요?
- **함수 시그니처 변경**: 해당 함수의 JSDoc/주석 업데이트 필요?

### 안내 방식

```
📝 문서 업데이트 감지:

코드 변경에 따라 문서 업데이트가 필요합니다:

✅ 자동 업데이트:
- README.md: API 엔드포인트 목록 (3개 → 5개)

❓ 확인 필요:
- .env.example: 새 환경 변수 DATABASE_URL 추가할까요?
- CLAUDE.md: 프로젝트 구조 섹션이 현재와 다릅니다

업데이트할까요?
```

## 업데이트 규칙

- **자동 업데이트**: 명확히 코드와 불일치하는 부분 (수치, 목록)
- **확인 후 업데이트**: 설명이나 가이드 변경이 필요한 부분
- **스킵**: 코드 변경과 무관한 문서

## 주의사항

- 사용자가 의도적으로 문서를 다르게 유지하는 경우가 있으므로, 항상 확인 후 수정한다
- README의 마케팅/소개 섹션은 건드리지 않는다
- 주석은 로직이 변경된 경우에만 업데이트 제안한다

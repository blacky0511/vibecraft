## 1단계. 코드 준비 확인

> **작성 가이드**: 배포할 코드가 올바르게 준비되었는지 확인합니다.

- [ ] 모든 기능이 완성되어 코드 리뷰를 통과했다
- [ ] main(또는 배포 대상) 브랜치에 올바르게 병합되었다
- [ ] 병합 후 불필요한 브랜치를 정리했다
- [ ] `.env` 파일에 비밀 정보가 포함되어 git에 올라가지 않았다
- [ ] `package-lock.json` / `yarn.lock` / `pom.xml` 등 의존성 파일이 커밋되어 있다

## 3단계. 환경 설정 확인

> **작성 가이드**: 운영 서버의 환경 변수와 설정이 올바른지 확인합니다.

- [ ] 운영 환경 변수(`.env.production`)가 최신 상태로 서버에 설정되어 있다
- [ ] 새로 추가된 환경 변수가 있다면 서버에 반영되었다
- [ ] API 키, 외부 서비스 연동 정보가 운영용 값으로 설정되어 있다
- [ ] 개발/테스트용 데이터나 설정이 운영 코드에 남아있지 않다
- [ ] 로그 레벨이 운영 환경에 맞게 설정되어 있다 (debug → info/error)

## 6단계. 배포 후 확인

> **작성 가이드**: 배포가 완료된 후 실제 서비스가 정상 동작하는지 확인합니다.

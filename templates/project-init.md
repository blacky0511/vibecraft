## 3. 초기 폴더 구조

> **작성 가이드**: 프로젝트 시작 시점의 폴더 구조를 미리 정의합니다.
> 나중에 파일이 많아질수록 폴더 정리가 힘들어지므로, 처음에 기준을 세워두는 것이 중요합니다.

```
프로젝트이름/
├── src/                  # 소스 코드
│   ├── components/       # 재사용 가능한 UI 컴포넌트
│   ├── pages/            # 페이지 컴포넌트 (Next.js 기준)
│   ├── api/              # API 호출 함수
│   ├── hooks/            # 커스텀 훅
│   ├── utils/            # 유틸리티 함수
│   ├── styles/           # 스타일 파일
│   └── types/            # TypeScript 타입 정의
├── public/               # 정적 파일 (이미지 등)
├── docs/                 # 문서 (설계서, 계획서 등)
├── .env.local            # 환경 변수 (git에 올리지 않음)
├── .env.example          # 환경 변수 예시 (git에 올림)
├── .gitignore
├── CLAUDE.md             # AI 작업 가이드
└── README.md
```

## 4. 설치 및 실행 명령어

> **작성 가이드**: 프로젝트를 처음 셋업하고 실행하는 명령어를 단계별로 기록합니다.
> 새로운 팀원이나 미래의 자신이 읽어도 따라할 수 있어야 합니다.

### 프로젝트 생성

```bash
# 예: Next.js 프로젝트 생성
npx create-next-app@latest 프로젝트이름 --typescript --tailwind --app

# 예: Spring Boot 프로젝트는 Spring Initializr에서 생성
# https://start.spring.io
```

### 의존성 설치

```bash
# 기본 패키지 설치
npm install

# 추가로 설치할 패키지
npm install (패키지명)
```

### 환경 변수 설정

1. `.env.example` 파일을 복사하여 `.env.local` 파일을 만든다
2. 각 항목에 실제 값을 채워넣는다

```bash
# macOS / Linux
cp .env.example .env.local

# Windows
copy .env.example .env.local
```

```env
# .env.example (여기에 필요한 환경 변수 목록을 정의)
DATABASE_URL=
JWT_SECRET=
NEXT_PUBLIC_API_URL=
```

### 개발 서버 실행

```bash
# 개발 환경 실행
npm run dev

# 빌드 (운영 배포용)
npm run build

# 빌드 결과 실행
npm run start
```

## 5. Git 설정

> **작성 가이드**: Git 저장소를 초기화하고 원격 저장소와 연결합니다.

### 초기화 및 첫 커밋

```bash
# Git 저장소 초기화
git init

# .gitignore 파일 생성 (아래 내용 참고)
# 첫 커밋
git add .
git commit -m "[설정] 프로젝트 초기 설정"

# 원격 저장소 연결
git remote add origin (저장소 URL)
git push -u origin main
```

### .gitignore 필수 항목

```gitignore
# 환경 변수 (절대 올리면 안 됨)
.env
.env.local
.env.production

# 의존성 폴더
node_modules/
.gradle/
target/

# 빌드 결과물
.next/
dist/
build/
out/

# 운영 체제 파일
.DS_Store
Thumbs.db

# IDE 설정
.vscode/settings.json
.idea/
*.iml
```

### 브랜치 전략

```
main (운영 - 항상 안정적인 코드)
  └── feature/기능이름 (새 기능 개발)
  └── fix/버그이름 (버그 수정)
```

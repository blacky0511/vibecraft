## 4. API 설계

> **작성 가이드**: 백엔드 API가 있는 경우 작성합니다. 프론트엔드가 어떤 주소로 요청을 보내고, 어떤 응답을 받는지 정의합니다.

### API 목록

| 메서드 | 경로 | 설명 | 인증 필요 |
|-------|------|------|---------|
| GET | /api/example | 예시 조회 | 아니오 |
| POST | /api/example | 예시 생성 | 예 |
| PUT | /api/example/:id | 예시 수정 | 예 |
| DELETE | /api/example/:id | 예시 삭제 | 예 |

### 요청/응답 예시

**POST /api/example**

요청 (Request Body):
```json
{
  "name": "예시 이름",
  "description": "예시 설명"
}
```

응답 (Response):
```json
{
  "success": true,
  "data": {
    "id": 1,
    "name": "예시 이름"
  },
  "message": "생성 완료"
}
```

## 6. 파일 구조

> **작성 가이드**: 새로 만들 파일과 수정할 파일을 미리 정리합니다. 빠진 파일이 없는지 확인하는 용도입니다.

```
프로젝트루트/
├── 새로 만들 파일 (신규 🆕)
│   ├── src/components/ExampleComponent.tsx 🆕
│   └── src/api/exampleApi.ts 🆕
│
└── 수정할 파일 (수정 ✏️)
    ├── src/pages/index.tsx ✏️
```

# 검증 보고서 (Check Report)

> **작성 가이드**: PDCA의 Check 단계에서 작성하는 문서입니다.

## 3. 달성률 계산

> **작성 가이드**: 아래 공식으로 달성률을 계산합니다.
> 달성률 = (완료된 필수 요구사항 수 ÷ 전체 필수 요구사항 수) × 100

| 항목 | 수치 |
|------|------|
| 전체 필수 요구사항 수 | 개 |
| 완료된 필수 요구사항 수 | 개 |
| 테스트 통과 수 | 개 |
| **최종 달성률** | **%** |

**판정**: ⬜ 90% 이상 → Act 단계 진행 / ⬜ 90% 미만 → Do 단계로 복귀

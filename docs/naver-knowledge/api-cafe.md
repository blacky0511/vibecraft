# 네이버 카페 API 체계 + 진단 트리

> 최종 확인일: 2026-03-30

---

## 1. 카페 API 체계

### 1-1. 접근 권한

네이버 카페는 다층 권한 구조를 가진다. 자동화 전에 권한 체크가 필수다.

```
카페 공개 여부 → 가입 여부 → 멤버 등급 → 게시판별 권한
```

**카페 공개 유형:**

| 유형 | 글 읽기 | 가입 방식 | 자동화 가입 |
|------|--------|----------|-----------|
| 공개 카페 | 비회원도 가능 | 바로 가입 | 가능 |
| 준공개 카페 | 비회원도 일부 가능 | 승인 필요 | 제한적 (승인 대기) |
| 비공개 카페 | 회원만 가능 | 초대 또는 승인 | 불가 (수동 승인 필요) |
| 질문 답변 카페 | 비회원도 일부 가능 | 질문 답변 후 가입 | 검토 필요 |

### 1-2. 글쓰기 API

| 엔드포인트 | 메서드 | 용도 |
|-----------|--------|------|
| `/ca-fe/cafes/{cafeId}/articles` | POST | 게시글 작성 |
| `/ca-fe/cafes/{cafeId}/articles/{articleId}` | PUT | 게시글 수정 |
| `/ca-fe/cafes/{cafeId}/articles/{articleId}` | DELETE | 게시글 삭제 |

**필수 파라미터:**
- `cafeId`: 카페 고유 번호
- `menuId`: 게시판 번호
- `subject`: 글 제목
- `content`: 본문 (HTML 또는 에디터 포맷)
- CSRF 토큰: 필수
- `useSafeContent`: XSS 방지 플래그 (필수)

**요청 헤더 필수:**
- `Referer`: `https://cafe.naver.com/...`
- `Cookie`: `NID_AUT` + `NID_SES` + `NNB` + 카페 멤버 쿠키
- `Content-Type`: `application/json` 또는 `application/x-www-form-urlencoded`

### 1-3. 댓글 API

| 엔드포인트 | 메서드 | 용도 |
|-----------|--------|------|
| `/ca-fe/cafes/{cafeId}/articles/{articleId}/comments` | POST | 댓글 작성 |
| `/ca-fe/cafes/{cafeId}/articles/{articleId}/comments/{commentId}` | PUT | 댓글 수정 |
| `/ca-fe/cafes/{cafeId}/articles/{articleId}/comments/{commentId}` | DELETE | 댓글 삭제 |

**대댓글 처리:**
- `refCommentId` 파라미터로 상위 댓글 지정
- 대댓글도 동일한 댓글 API 사용

**댓글 제한:**
- 일일 댓글 횟수 제한 (카페별 상이)
- 최소 글자 수 제한 (카페별 설정)
- 동일 내용 반복 댓글 차단

### 1-4. 첨부파일 API

| 엔드포인트 | 메서드 | 용도 |
|-----------|--------|------|
| `/ca-fe/cafes/{cafeId}/upload` | POST (multipart) | 이미지/파일 업로드 |

**업로드 규칙:**
- `multipart/form-data` 형식
- 파일 크기 제한: 이미지 10MB, 일반 파일 카페별 상이
- 업로드 성공 시 CDN URL 반환
- 첨부 가능 파일 유형은 카페 설정에 따라 다름

## 2. 멤버 등급별 권한 체크

### 2-1. 기본 등급 구조

네이버 카페는 카페 매니저가 등급을 설정할 수 있다. 일반적인 등급 구조:

| 등급 | 일반 게시판 | 공지사항 | 특수 게시판 | 이미지 첨부 |
|------|-----------|---------|-----------|-----------|
| 새내기 (가입 직후) | 제한적 | 불가 | 대부분 불가 | 카페별 상이 |
| 정회원 | 가능 | 불가 | 카페별 상이 | 가능 |
| 우수회원 | 가능 | 불가 | 대부분 가능 | 가능 |
| 매니저/부매니저 | 가능 | 가능 | 가능 | 가능 |
| 카페장 | 모든 권한 | 가능 | 가능 | 가능 |

### 2-2. 등급별 자동화 주의사항

- **새내기 등급**: 글쓰기가 제한될 수 있음. 등급 승급 조건을 먼저 확인
- **등급 업 조건**: 방문 횟수, 댓글 수, 가입 기간 등 카페별 상이
- **등급 확인 API**: 카페 멤버 정보 조회로 현재 등급 파악 가능
- **등급별 게시판 접근 권한**: 게시판 목록 API에서 `writable` 필드 확인

## 3. 카페 금지어 필터

### 3-1. 금지어 체계

네이버 카페는 두 가지 금지어 필터를 운영한다.

| 유형 | 관리 주체 | 대상 | 공개 여부 |
|------|----------|------|----------|
| 네이버 공통 금지어 | 네이버 | 모든 카페 | 비공개 |
| 카페별 자체 금지어 | 카페 매니저 | 해당 카페만 | 비공개 (매니저만 확인) |

### 3-2. 금지어 포함 시 동작

```
글 작성 시 금지어 포함
├── 즉시 차단: 글 발행 자체가 거부됨 (에러 응답)
├── 자동 삭제: 발행은 되지만 곧바로 삭제됨
├── 관리자 검토 대기: 발행은 되지만 공개 전 매니저 승인 필요
└── 경고 후 허용: 경고 메시지만 표시하고 발행 가능 (일부 카페)
```

### 3-3. 금지어 대응

- 금지어 목록은 비공개이므로 사전 확인 불가
- 발행 실패 시 에러 메시지에서 "금지어" 관련 키워드 확인
- 금지어로 의심되는 단어를 하나씩 제거하며 재시도 (이분 탐색)
- 카페마다 금지어가 다르므로 동일 내용이 A 카페에서는 되고 B 카페에서는 안 될 수 있음

## 4. 가입 후 N일 글쓰기 제한

### 4-1. 제한 구조

카페 매니저가 설정할 수 있는 가입 후 글쓰기 제한:

| 설정 | 효과 | 자동화 영향 |
|------|------|-----------|
| 가입 즉시 글쓰기 가능 | 제한 없음 | 가입 후 바로 글쓰기 |
| 가입 후 N일 제한 (1~30일) | N일 후부터 글쓰기 가능 | 대기 기간 필요 |
| 방문 N회 이상 | 방문 횟수 충족 후 글쓰기 | 방문 기록 누적 필요 |
| 댓글 N개 이상 | 댓글 작성 후 글쓰기 | 댓글 먼저 작성 |

### 4-2. 제한 감지

- 글쓰기 시도 시 "아직 글을 작성할 수 없습니다" 에러
- 에러 응답에 남은 일수/조건 포함되는 경우 있음
- 카페 멤버 정보 API에서 가입일 확인 가능

### 4-3. 자동화 시 대응

```
1. 카페 가입 API 호출 → 성공
2. 멤버 정보 조회 → 가입일, 현재 등급 확인
3. 글쓰기 제한 여부 확인
   ├── 제한 없음 → 바로 글쓰기
   ├── N일 제한 → 대기 후 재시도
   └── 조건 미충족 → 조건 충족 작업 (방문, 댓글 등) 먼저
```

## 5. IP 기반 카페 차단

### 5-1. 차단 트리거

| 트리거 | 설명 | 차단 범위 |
|--------|------|----------|
| 동일 IP 다수 카페 활동 | 하나의 IP에서 여러 카페에 동시 활동 | IP 단위 |
| 단시간 동일 내용 게시 | 같은 글을 여러 카페에 올림 | IP + 계정 |
| 대량 가입 | 짧은 시간에 다수 카페 가입 | IP + 계정 |
| 스팸 신고 누적 | 다른 회원의 신고 | 계정 단위 |

### 5-2. 차단 증상

- 카페 접근 시 403 또는 차단 안내 페이지
- 글 작성 시 "비정상적인 접근" 에러
- 카페 가입 시도 시 실패
- 프록시 사용 시에도 패턴 기반으로 감지 가능 (쿠키, 행동 패턴)

### 5-3. 대응

- 프록시 로테이션 (단, 대규모 사용 시 법적 리스크)
- 카페별 활동 간격 충분히 확보
- 동일 내용 금지 (각 카페에 맞게 내용 변형)
- IP 차단 해제는 일정 기간 경과 후 자동 (또는 네이버 문의)

## 6. 카페 진단 트리

### 6-1. 접근 권한 단계

```
카페 존재 확인
├── 404 → 카페 URL 변경 / 카페 폐쇄
│   ├── 카페 ID/URL 재확인
│   └── 카페가 삭제/비공개 전환되었을 가능성
└── 존재 ↓

카페 가입 여부
├── 비회원 → 가입 API 호출 필요
│   ├── 공개 카페? → 자동 가입 가능
│   │   └── 가입 API: POST /ca-fe/cafes/{cafeId}/join
│   ├── 승인 필요? → 자동화 불가 (수동 승인 대기)
│   │   └── 가입 신청 API 호출 → 매니저 승인 대기
│   └── 질문 답변 필요? → 답변 자동화 검토
│       └── 질문 내용 파싱 → 답변 생성 → 가입 신청
└── 회원 ↓

멤버 등급 확인
├── 새내기 → 등급 제한 확인
│   ├── 일일 글쓰기 제한?
│   │   └── 카페 설정 확인 → 제한 초과 시 다음 날 재시도
│   ├── 특정 게시판 접근 불가?
│   │   └── 접근 가능한 게시판 목록 확인
│   ├── 이미지 첨부 불가?
│   │   └── 텍스트만 작성 또는 등급 업 후 재시도
│   └── 가입 후 N일 글쓰기 제한?
│       └── 가입일 확인 → 제한 기간 계산 → 대기 또는 조건 충족
└── 정회원 이상 ↓

게시판별 권한 차이
├── 일반 게시판 → 대부분 글쓰기 가능
├── 공지사항 → 매니저만 작성 가능
│   └── 매니저 권한이 아니면 다른 게시판 선택
└── 특수 게시판 → 등급별 상이
    └── 게시판 목록 API에서 writable 필드 확인
```

### 6-2. 글쓰기 단계

```
에디터 로딩
├── SmartEditor → 블로그와 유사한 에디터 구조
└── 간편 에디터 → 일부 카페에서 사용하는 경량 에디터

카페 금지어 필터
├── 네이버 공통 금지어 → 모든 카페에 적용
├── 카페별 자체 금지어 → 매니저가 설정
├── 금지어 포함 시
│   ├── 즉시 차단 → 에러 메시지 확인
│   ├── 자동 삭제 → 발행 직후 삭제 확인
│   └── 관리자 검토 대기 → 공개 여부 확인
└── 금지어 미포함 ↓

글 발행 API
├── CSRF 토큰 + useSafeContent 확인
│   ├── CSRF 토큰 누락 → 403 에러
│   └── useSafeContent 누락 → XSS 방지 에러
├── 필수 파라미터 확인
│   ├── cafeId, menuId, subject, content
│   └── 누락 시 400 에러
└── 응답 확인
    ├── articleId 반환 → 성공
    ├── 에러 코드 반환 → 에러 유형별 대응
    │   ├── 권한 부족 → 등급 확인
    │   ├── 글쓰기 제한 → 제한 조건 확인
    │   ├── 금지어 → 내용 수정
    │   └── 서버 에러 → 재시도
    └── 발행 후 글 접근 확인

IP 기반 카페 차단 확인
├── 동일 IP 다수 카페 활동 감지?
│   └── 카페별 활동 간격 확보
├── 단시간 동일 내용 게시?
│   └── 내용 변형 필요
└── 프록시 사용 시에도 패턴 감지 가능
    └── 쿠키/행동 패턴으로 연결 → 쿠키 분리 필요

댓글 API
├── 댓글 작성 → commentId 반환 확인
├── 대댓글 → refCommentId 설정 확인
└── 댓글 제한
    ├── 일일 횟수 초과 → 다음 날 재시도
    ├── 최소 글자 수 미달 → 내용 보충
    └── 동일 내용 반복 → 내용 변형
```

## 7. 법적 리스크 참조

카페 자동화와 관련된 법적 리스크:

| 행위 | 분류 | 관련 법률 | 비고 |
|------|------|----------|------|
| 본인 카페 관리 자동화 | 합법 (Green) | - | 자기 카페 관리 |
| 카페 글쓰기 자동화 (본인 계정) | 회색 (Yellow) | 네이버 이용약관 | 계정 잠금 리스크 |
| 여러 카페 동시 홍보 글 | 회색 (Yellow) | 네이버 이용약관 | 스팸 판정 + IP 차단 |
| 대량 카페 가입 + 홍보 | 불법 (Red) | 형법 314조 (업무방해) | 업무방해 |
| 타인 계정으로 카페 활동 | 불법 (Red) | 정보통신망법 49조 | 5년 이하 징역 |
| 자동 댓글 스팸 | 불법 (Red) | 형법 314조 (업무방해) | 업무방해 |

> 진단 보고서에는 반드시 현재 자동화의 법적 분류를 포함해야 한다.
> 특히 여러 카페에 동시 활동하는 경우 업무방해죄 적용 가능성이 있으므로 주의한다.

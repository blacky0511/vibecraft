# vibecraft Standard Style

## 응답 규칙

1. 결과 위주로 간결하게 응답한다
2. 코드 변경 시 변경 사항만 요약한다
3. 워크플로우 진행 상황은 한 줄로 표시한다:
   > 새 기능 > M > 실행 중 (3/5 완료)
4. Learning Point는 포함하지 않는다
5. 사용자가 물어보지 않은 것은 설명하지 않는다
6. 코드 블록은 변경된 부분만 보여준다
7. 검증 결과는 통과/실패만 간략히 표시한다
8. 응답 마지막에 마무리 블록을 간결하게 표시한다:

   **중요: 인용 블록(`>`) 사용 금지 - 터미널에서 회색으로 보임.**

   ```markdown
   ---

   📍 **현재 위치**: 새 기능 > M > 실행 중 (3/5)

   🚀 **다음 액션:**
   1. `"테스트 돌려줘"`
   2. `"커밋해줘"`
   3. `"배포 준비해줘"`
   ```

   작성 규칙:
   - 현재 맥락에서 가장 자연스러운 다음 행동을 제안한다
   - 번호 + 백틱 코드 입력 문장만 간결하게 (설명 최소화)
   - 뻔하거나 반복적인 제안은 피한다
